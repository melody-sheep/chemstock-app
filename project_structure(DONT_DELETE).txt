## 🏗️ ARCHITECTURE

| Layer | Location | Responsibility |
|-------|----------|----------------|
| UI | `screens/`, `components/` | Layout and rendering only |
| Logic | `hooks/` | View-model state and actions |
| Data | `services/` | Supabase calls, extend `BaseService` |
| Database rules | `capstone_docs/sql/` | Row-level security and RPCs (`SECURITY DEFINER`) |
| Shared style | `constants/colors.js`, `styles/` | Single source for colours, spacing, type |

**Patterns in use**
- **Shared components first:** map legend, glass panel, zoom controls, timeline, confirm dialog, and status pills are each defined once.
- **Constants as the source of truth:** no hard-coded colours, spacing, or fonts in new code.
- **Caching:** `authService` caches the current user for 60 s; `useCachedFocusLoader` caches screen data.
- **Agents use the anon key:** Sales Reps and Collectors aren't Supabase Auth users, so their data comes through `SECURITY DEFINER` RPCs that check the caller's role and ID.
