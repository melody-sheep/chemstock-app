The user clarified that stock a Sales Rep still physically holds must remain
in the backpack after a daily report. It must carry into the next report and
must not be treated as confirmed missing stock merely because it was not sold
or returned that day.

BEHAVIORAL CHANGE PREPARED

Old behavior:
- The report-building database function set every included SR inventory
  batch's remaining_quantity to zero when a report was filed.
- Remaining unsold units could therefore disappear from the backpack and
  show up as missing.

Prepared behavior:
- The new report function records the starting in-custody quantity.
- It deducts only the reported sold and returned units from SR inventory,
  consuming batches in FIFO order.
- Remaining units stay in the backpack and are represented as a carry-forward
  balance. Example: 1,000 in custody - 300 sold = 700 carried forward.
  If 500 more are received and 200 are then sold, the next balance is 1,000.
- Auto-filed zero-sales/zero-return reports also retain the inventory.
- The next manual report accepts sales quantities since the last submitted
  report, including unreported sales from missed days. Those sales are stored
  against the date of the submitted report; the system cannot infer or
  allocate sales to each missed calendar date.
- Earlier carry-forward rows remain in report history but are excluded from
  active discrepancy lists to avoid repeating the same balance.
- Pending return requests tied to an older carry-forward row are rejected
  when a newer report supersedes it; the Sales Rep is notified to submit a
  request against the current report if needed.
- Accepting a return request for a carry-forward balance removes the approved
  quantity from the SR's matching branch/batch inventory and credits the
  branch inventory.
- Manager report loss totals exclude negative carry-forward balances.
- SR and Manager notifications use the wording "Missing on report — still in
  backpack; carried forward" and clarify this is a report discrepancy, not
  confirmation of physical loss.
