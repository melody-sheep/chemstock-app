## │ 6. QUICK REFERENCE - SQL COMMANDS                                           │
## ├─────────────────────────────────────────────────────────────────────────────┤

### 📊 Check audit logs
```sql
SELECT COUNT(*) FROM activation_audit_log;
```

### 🔍 View all recent logs (service_role only)
```sql
SELECT * FROM recent_audit_logs;
```

### 📋 Get audit stats
```sql
SELECT 
  COUNT(*) as total,
  COUNT(*) FILTER (WHERE status = 'success') as successful,
  COUNT(*) FILTER (WHERE status = 'failed') as failed,
  ROUND(100.0 * COUNT(*) FILTER (WHERE status = 'success') / COUNT(*), 1) as success_rate
FROM activation_audit_log;
```

### 🔑 Check key usage
```sql
SELECT 
  code,
  manager_name,
  is_used,
  used_at,
  expires_at
FROM activation_keys
WHERE is_used = false AND expires_at > NOW()
ORDER BY created_at DESC;
```

### 📊 View table structure
```sql
SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_name = 'activation_audit_log'
ORDER BY ordinal_position;
```

### 🔒 View RLS policies
```sql
SELECT schemaname, tablename, policyname, cmd, permissive, roles
FROM pg_policies
WHERE schemaname = 'public'
ORDER BY tablename, policyname;
```
